# Contributing

## Development setup

```bash
make install        # .venv with the package in editable mode + dev and figures extras
make check          # ruff + pytest (offline, about 30 s), the same as CI
make serve          # results explorer on http://localhost:8000
```

Python 3.12+ is required. Dependencies are pinned exactly in `pyproject.toml` so that bootstrap and NLS results reproduce bit for bit. Bump a pin only on purpose, and say in the commit whether any committed number changed.

## Research rules

This repository is a pre-registered study. The rules below protect the credibility of its results and take priority over convenience.

1. **`docs/HYPOTHESES.md` is frozen.** Never edit it. Interpretations, deviations and bugs that touch the analysis go into `docs/DECISIONS.md`, dated and written *before* the run they govern. That log is append-only.
2. **The test split stays locked.** `ofi.io` refuses to load 2026-04-01 to 2026-09-30 except inside `ofi final-test`, which already ran once and refuses to run again. Don't add other ways to load those days.
3. **Every analysis run is logged.** Anything that computes a result appends rows to `research/trial_ledger.csv` via `ofi.ledger.log_run`, so the amount of testing stays visible.
4. **Raw vendor data is never committed.** Commit the code that downloads it. `data/` is git-ignored.
5. **Results are committed whatever they show.** Generated reports in `reports/` and `research/` are outputs: change them by re-running the step that writes them, not by hand.

## Code layout

| Path | What lives there |
|---|---|
| `src/ofi/ofi.py`, `regress.py`, `stats.py`, `predict.py` | The methods: OFI and bucketing, per-window regressions, bootstrap and NLS, prediction and costs. Pure functions, unit-tested. |
| `src/ofi/io.py`, `quality.py`, `ledger.py`, `config.py` | Downloads and the test-date guard, data-quality checks, the trial ledger, paths and the sample split. |
| `src/ofi/pipeline/` | One module per `ofi` command. Each exposes `add_arguments(parser)` and `run(args)`; register new commands in `src/ofi/cli.py`. |
| `site/` | The static results explorer. `data.js` is generated by `ofi site`; `index.html`, `styles.css` and `app.js` are hand-written. |
| `tests/` | Unit tests per module, plus `test_pipeline.py`, which runs the real CLI end to end on synthetic files. |

## Tests

Tests must run offline and quickly. Mock the network (see `tests/test_io.py`) and generate small synthetic books (see `tests/test_bucket.py`, `tests/test_pipeline.py`). When you fix a bug, add a regression test that fails without the fix.

If you change anything the results explorer shows, run `ofi site` and commit the regenerated `site/data.js`; CI fails when it is stale.
